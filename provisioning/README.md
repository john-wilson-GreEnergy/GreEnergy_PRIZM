# PRIZM Provisioning Workspace

- PRIZM Provisioning Workspace is the preferred way to validate and plan provisioning.
- Templates are repo-managed and serve as reference/preview assets.
- Site-files are technician-copied and not committed.
- Execution remains disabled until controlled execution is implemented.
- No credentials should be stored in the repo.
- Future controlled execution must collect credentials at runtime or from an approved local secret store outside git.
